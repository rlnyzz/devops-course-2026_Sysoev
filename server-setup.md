## 9. Контейнеризация

- **Способ установки Docker Engine:** официальный репозиторий Docker (docker-ce, docker-ce-cli, containerd.io, docker-buildx-plugin, docker-compose-plugin).
- **Версия Docker:** 27.x (или какая у тебя установилась, можно посмотреть командой `docker version`).
- **Участники группы docker:** пользователь `devops`.
- **Расположение проекта на сервере:** `/home/devops/app`.
- **Расположение файла .env и его права:** `/home/devops/app/.env`, права `600` (владелец `devops`).
- **Публикуемые порты и адреса:** приложение доступно на `127.0.0.1:5000` (только локально). Порт СУБД (5432) не публикуется.
- **Именованные тома:** `app_db_data` (для хранения данных PostgreSQL).
- **Конфигурация обратного прокси-сервера:** Nginx настроен на перенаправление запросов с `https://devops.local/app/` на `http://127.0.0.1:5000/`.
